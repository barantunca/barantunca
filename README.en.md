I'm a third-year software engineering student, and most of the software I build these
days I build together with AI agents. I leave the repetitive, time-consuming parts to
them; what gets built, how it's split up and whether the code that comes out is actually
right is my call.

What I really care about is the side the user sees. A screen can work and still not be
done, if it's tiring to use. I like spending time on those small details.

## What I've built

- **[YerBul](https://yer-bul.vercel.app)**: For finding a place to sit on campus.
  Shows how full the libraries, study halls and cafés are, on a map, based on reports
  from students. I'm working on the mobile version right now.
  · [source](https://github.com/barantunca/yer-bul-showcase)
- **[Berber Randevu](https://berber-randevu-wheat.vercel.app)**: A simple app that
  lets barbers keep track of their appointments from their phone.
  · [source](https://github.com/barantunca/berber_randevu)

## What I use

TypeScript, React, React Native (Expo), Python, FastAPI, Supabase, PostgreSQL. Figma for design.
