I'm in my third year. What interests me isn't individual features but why a system is
split the way it is: which rule belongs where, what a layer should never know about,
and whether a decision I make today will still be defensible six months from now.

I use AI tools heavily, but I don't trust the code they produce without questioning it.
My real job is drawing the boundaries — deciding what belongs where, and what must
never be trusted. I'm still a student and don't claim to know everything, but I've
learned you get nowhere without digging into the things that puzzle you.

## Currently

- Porting **YerBul** to React Native + Expo, with the data layer moving to Supabase.
- Keeping domain logic in a pure core that knows nothing about React, the database or
  the theme — so it can be tested without rendering a single screen. I record
  architectural decisions as ADRs, because nobody remembers the reasoning half a year later.
- What I learned this term: accessibility isn't polish applied at the end. My previous
  color palette looked fine to the eye, yet all five status badges failed the contrast test.
